# 🍔 Clone Front-End — FAQ Produits McDonald’s France

Ce projet est une reproduction front-end d’une page du site McDonald’s France, plus précisément la FAQ des produits utilisés dans les restaurants.
Il s’agit d’un exercice de développement visant à reproduire l’interface, la mise en page, les animations et la responsivité du site original.

## ⚠️ IMPORTANT : Ce projet est un simple clone pédagogique.
Aucune donnée réelle, aucune API, aucune fonctionnalité back-end du site officiel n’est intégrée ni accessible.
Tout le contenu présent est statique et destiné à l’apprentissage.

## ✨ Fonctionnalités
### 🎨 Interface fidèle

Mise en page inspirée du site officiel McDonald’s France.

Reproduction des sections principales de la FAQ.

Design soigné, typographies et couleurs proches de la version originale.

### 📱 Site responsive

L’application a été pensée pour fonctionner correctement sur :

Téléphones

Tablettes

Ordinateurs portables

Écrans larges

Les éléments s’adaptent grâce à une grille flexible, des breakpoints appropriés et un ajustement des espacements.

### 🃏 Animations & Interactions

Animations sur les cartes de contenu (hover, transitions douces).

Apparition progressive de certains éléments au scroll.

Comportement fluide et agréable sur tous les appareils.

### 🔐 Aucun back-end, aucune donnée réelle

Le projet ne communique avec aucun service externe.

Aucun formulaire ni fonctionnalité liée aux vraies données McDonald’s.

Toutes les informations visibles sont statistiques ou fictives, utilisées uniquement pour le visuel.
